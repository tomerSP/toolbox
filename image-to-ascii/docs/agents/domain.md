# Domain docs

## Layout

Single-context within `image-to-ascii/`: `CONTEXT.md` and `docs/adr/`.
All paths in this file are relative to that subsite directory.

## Before exploring

Read `CONTEXT.md` and ADRs relevant to the work.
If absent, proceed silently. Domain-modeling creates them lazily
when terminology or decisions are resolved.

## Vocabulary

Use terms defined in `CONTEXT.md` in issues, proposals,
hypotheses, and tests. Reconsider unfamiliar terms or note
real glossary gaps for domain-modeling.

## Decisions

Surface contradictions with existing ADRs explicitly,
identifying the ADR and reason for reopening the decision.
