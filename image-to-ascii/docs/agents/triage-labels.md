# Image-to-ASCII triage labels

Canonical roles map directly to tracker labels:

- `needs-triage`: maintainer evaluation needed.
- `needs-info`: waiting on reporter.
- `ready-for-agent`: fully specified; agent implementation ready.
- `ready-for-human`: human implementation required.
- `wontfix`: will not be actioned.

Use these strings whenever a skill names a triage role.
