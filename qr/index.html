Why can't I put a big file in a QR code?

A QR code is not storage — it is a printed string of at most 2,953 bytes, and that is the absolute ceiling at the lowest error-correction level. Compatible mode uses a data: URI, which costs about a third extra on top of the raw size, so the practical limit is roughly 2 KB. Raw-byte mode uses the full capacity, but ordinary scanners may not know the file type or how to save it. Packed mode spends a few bytes preserving the filename and type, but only this site promises to restore it. Enable multiple codes to split larger results across up to 16 Structured Append symbols; scanner support varies. Anything beyond that must be uploaded somewhere and linked to by URL.
